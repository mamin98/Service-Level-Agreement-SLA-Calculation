# SLA Deadline Calculator 🕒

A web-based application for calculating the SLA (Service Level Agreement) resolution deadline of complaints, based on business hours and configured closures.

## 🧰 Tech Stack

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Clean Architecture
- Swagger (for testing the API)

---

## ✅ Features

- Calculate SLA deadline for complaints based on:
  - Complaint priority
  - Business working hours
  - Weekend days
  - National holidays and partial business closures
- Supports file upload (optional screenshot)
- Soft delete for complaints (optional via Swagger)
